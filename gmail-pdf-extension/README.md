# Gmail: скачать письмо в PDF

Расширение для Chrome, которое добавляет в Gmail плавающую кнопку
«Скачать в PDF». По клику открытое письмо печатается через стандартный
диалог печати Chrome, где нужно выбрать принтер **«Сохранить как PDF»**
и нажать «Сохранить» — так письмо сохранится на диск в формате PDF.

Прямое сохранение файла в PDF в один клик без диалога печати браузерные
расширения делать не могут (Chrome не даёт такого API страницам), поэтому
кнопка использует системный диалог печати — это стандартный и надёжный
способ.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите переключатель **«Режим разработчика»** (Developer mode) в
   правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку `gmail-pdf-extension`.

## Использование

1. Откройте [Gmail](https://mail.google.com) и раскройте нужное письмо.
2. В правом нижнем углу нажмите синюю кнопку **«Скачать в PDF»**.
3. В открывшемся диалоге печати выберите принтер **«Сохранить как PDF»**
   и нажмите **«Сохранить»**.

Если открыта цепочка писем (тред), в PDF попадут все развёрнутые
(не свёрнутые) сообщения из неё.

## Структура

- `manifest.json` — манифест расширения (Manifest V3).
- `content.js` — добавляет кнопку и готовит письмо к печати.
- `print.css` — стили кнопки и стили для печати (скрывает всё, кроме
  письма).
- `icons/` — иконки расширения.
