# Gmail: скачать письмо в PDF

Расширение для Chrome с двумя способами получить PDF из письма Gmail —
без диалога печати, файл сразу скачивается.

## Способ 1. Кнопка в Gmail (быстро)

На странице открытого письма в Gmail появляется плавающая кнопка
**«Скачать в PDF»** (правый нижний угол). По клику письмо рендерится
и сразу скачивается как PDF-файл — картинкой высокого разрешения
(через `html2canvas` + `jsPDF`), без открытия диалога печати.

Подходит для быстрого сохранения «как выглядит на экране», включая
вёрстку и картинки. Текст в таком PDF не выделяется и не копируется —
это растровое изображение письма.

## Способ 2. Конвертер .eml → PDF (настоящее извлечение текста)

Более точный способ: реальное извлечение содержимого письма (тема,
от, кому, дата, вложения, текст) из исходного `.eml`-файла и генерация
**текстового** PDF — текст выделяется, копируется и ищется, файл
компактный.

1. В Gmail откройте письмо → значок **«⋮»** → **«Скачать сообщение»** —
   сохранится файл `.eml`.
2. Нажмите на иконку расширения в панели Chrome.
3. Выберите скачанный `.eml`-файл и нажмите **«Сконвертировать в PDF»**.
4. PDF скачается автоматически, имя файла — по теме письма.

Парсер `.eml` (`eml.js`) написан без внешних зависимостей: разбирает
MIME-заголовки, multipart-части, quoted-printable/base64,
RFC 2047-кодировку темы/имени отправителя, выбирает `text/plain`
(либо текст из `text/html`, если plain-версии нет), собирает список
вложений. PDF собирается через `jsPDF` со шрифтом Roboto (кириллица +
латиница вшиты в `vendor/fonts/roboto-cyrillic-font.js`), поэтому
русский текст в PDF корректный и выделяемый.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите переключатель **«Режим разработчика»** (Developer mode) в
   правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку `gmail-pdf-extension`.

## Структура

- `manifest.json` — манифест расширения (Manifest V3).
- `content.js`, `print.css` — кнопка «Скачать в PDF» в Gmail (способ 1).
- `popup.html`, `popup.js` — всплывающее окно конвертера `.eml → PDF`
  (способ 2).
- `eml.js` — парсер `.eml`/MIME без зависимостей.
- `vendor/html2pdf.bundle.min.js` — библиотека рендера DOM → PDF
  (способ 1).
- `vendor/jspdf.umd.min.js` — библиотека генерации текстового PDF
  (способ 2).
- `vendor/fonts/roboto-cyrillic-font.js` — шрифт Roboto (кириллица +
  латиница) в base64 для вставки в PDF (Google Fonts, лицензия
  Apache-2.0).
- `icons/` — иконки расширения.
